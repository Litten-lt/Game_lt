# 实现路线

更新日期：2026-08-12

## 当前基线

当前工程是无敌人的修尔基础机动验证场景，已经完成待机、高速悬行、二段跳、地面瞬移和空中冲刺。角色造型与基础运动方向已经冻结，后续不再恢复早期流岚战斗 Demo 或骨骼拼装实验。

## M1：首组爪击

- 定稿三段普通攻击的起手、命中和收招关键帧。
- 为每段攻击定义前摇、有效帧、后摇和输入缓存。
- 建立独立 Hitbox/Hurtbox，不按角色间距离判定。
- 加入轻量命中停顿、爪痕和击退。

验收：三段攻击衔接连续，可以从待机、移动和跳跃状态进入，并能稳定返回基础机动状态。

## M2：训练目标与战斗闭环

- 加入一个静态训练目标和一个基础近战敌人。
- 实现生命值、受击、无敌帧、死亡与重置。
- 验证地面连击、空中追击和瞬移接近的用途。

验收：玩家能够完成一场短战斗，失败原因与命中反馈清楚。

## M3：肉鸽房间原型

- 制作进入、封锁、清场、奖励、离开流程。
- 加入两种敌人组合和三种基础强化选择。
- 建立角色能力与通用强化分离的数据结构。

验收：可连续游玩三个房间并完成一次强化选择。

## M4：垂直切片

- 完成 10～15 分钟流程。
- 加入标题、暂停、失败、通关和基础存档。
- 完成镜头、手柄、音效、性能与 Windows 导出。
- 进行外部试玩并记录死亡点、理解成本和完成时间。
