# 新角色设定

## 角色方向

- 原型：长发、兽耳、蓬松长尾的女性剑士。
- 服装：白灰色中式无袖长裙，保留少量红色纹样和深色短靴。
- 武器：长直剑。
- 游戏画风：低分辨率、粗像素块、有限色阶、清晰深色外轮廓。

## 参考图职责

- 原型图一：正面造型、服装结构与基础配色。
- 原型图二：长发、兽耳、尾部轮廓与佩剑细节。
- 风格图三：角色比例、像素尺寸、轮廓与简化程度；不继承其蓝色幽灵装饰或服装。
