# 豆包动作视频生成包

## 使用方法

每次只生成一个动作视频，并按编号上传该动作文件夹内的三张图片：

1. `01_外观基准.png`：锁定角色身份、服装、颜色、武器和像素画风。
2. `02_视角基准.png`：锁定右前 45° 横版游戏视角。
3. `03_动作原型.png`：只参考动作姿势和运动趋势。

把对应目录中的 `提示词.txt` 完整复制给豆包。不要让豆包在同一个视频中依次表演多个动作。

## 统一输出要求

- 横屏 3:2 或 16:9，角色完整处于画面中央。
- 固定正交镜头，不推拉、不摇移、不旋转。
- 纯绿色背景，颜色均匀，无地面、阴影、渐变和光斑。
- 右前 45° 朝向，人物大小在整个视频中绝对不变。
- 像素画边缘清晰，不插值成平滑绘画风。
- 首尾姿势无缝衔接，动作在原地完成。
- 不添加文字、UI、敌人、刀光、烟雾、速度线或粒子特效。

## 推荐生成顺序

1. 待机呼吸
2. 行走循环
3. 奔跑循环
4. 跳跃完整动作
5. 普通攻击
6. 冲刺

先生成低运动幅度的待机和行走，确认角色不会变脸、变装或缩放，再继续高速动作。
