# Game_lt

Godot 4.7 制作的 2D 横版战斗肉鸽原型。当前阶段聚焦首个角色“修尔”的基础机动手感与动画一致性，不放置敌人。

## 当前完成

- 六帧完整角色待机，支持左右镜像
- 五帧高速悬行循环
- 与待机共用造型的六帧跳跃
- 二段跳
- 地面瞬移与每次滞空一次的空中冲刺
- 瞬移渐变角色残影
- Godot 无窗口行为回归测试

## 运行

1. 使用 Godot 4.7 打开 `game/FighterRPGDemo/project.godot`。
2. 按 `F6` 或 `F5` 运行。

操作：

- `A/D`：高速悬行
- `Space/K`：跳跃；空中可再跳一次
- `L`：地面瞬移；空中每次滞空可冲刺一次

## 目录

- `game/FighterRPGDemo/`：当前可运行 Godot 工程
- `docs/`：项目规划、决策与角色开发记录
- `tools/`：当前图集的可复现构建工具

详细状态见 [修尔角色开发记录](docs/characters/XIUER.md)。

## 当前原则

- 角色造型一致性优先于帧数。
- 待机、跳跃使用同一角色比例和同源完整帧。
- 不使用从压平原画临时拆出的骨骼部件。
- 新动作先通过关键帧评审，再接入 Godot。
- `main` 保持可运行，实验素材不进入正式运行目录。
