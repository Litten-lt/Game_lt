# Xiaoguang project structure

- `assets/characters/xiaoguang`: runtime character animation and effect PNGs.
- `assets/environments/shrine`: runtime level backgrounds.
- `scenes`: Godot scenes.
- `scripts`: gameplay scripts.
- `source_assets`: source videos, design references, PSD edits, prompts, and tooling. Godot ignores this directory.

Generated Godot import data lives in `.godot` and can always be regenerated.
